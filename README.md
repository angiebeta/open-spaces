🌿 Open Spaces 
Este proyecto consiste en el desarrollo de una página web estática de una tienda siguiendo un diseño proporcionado en Zeplin. Además, la web debe ser responsive y aplicar buenas prácticas de maquetación con HTML y CSS.

🛠️ Tecnologías utilizadas
- HTML
- CSS (Sass)
- Flexbox y CSS Grid
- Media Queries



🧩 Estructura de la maquetación
La página se compone de los siguientes módulos:

1. Disfruta creando espacios: 

- Maquetado con Flexbox
- Ocupa el alto completo de la ventana

2. Volverse organizado se siente mejor con Open Spaces:

- Maquetado con CSS Grid

3. Envío gratis garantizado:

- Maquetado libre con propiedades CSS

4. Disfruta creando espacios:

- Maquetado libre con propiedades CSS

5. Footer:

- Maquetado con Flexbox
- Enlaces en columnas "NOSOTROS" y "TIENDA" apuntan a adalab.es
- Botón de flecha enlaza al inicio de la página (usa FontAwesome)

📱 Diseño responsive
La web se adapta correctamente a los siguientes tamaños:

- Móvil (mobile first)
- Tablet (≥ 900px)
- Desktop (≥ 1728px)

🍔 Menú hamburguesa
- Fijo en la parte superior en tablet y móvil
- Enlace a adalab.es
- No despliega submenús
- El menú superior permanece visible al hacer scroll

✨ Interacciones
- Hover en botón “Comprar ahora” con cambio de estilo (color, tamaño, etc.)
- Enlaces del pie apuntan a adalab.es
- Flecha del footer enlaza al inicio
